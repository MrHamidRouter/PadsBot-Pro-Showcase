# معرفی PadsBot Pro

**ویترین عمومی محصول تجاری PadsBot Pro** — این مخزن فقط برای معرفی و مستندات عمومی است؛ سورس اصلی PHP، اطلاعات مشتریان، توکن‌ها و بکاپ‌ها در آن قرار نمی‌گیرند.

## تعرفه پیشنهادی

| دوره | مجموع با میزبانی (USDT) |
|---|---:|
| ماهانه | **۱۲** |
| سه‌ماهه | **۳۳** |
| شش‌ماهه | **۶۶** |
| سالانه | **۱۲۳** |

تمام قیمت‌ها شامل یک لایسنس دامنه، مینی‌اپ اختصاصی و میزبانی مدیریت‌شده با مصرف متعارف روی سرور ما هستند (سهم میزبانی ۲ دلار در ماه). هزینه خرید و تمدید دامنه، خدمات شخص ثالث و مصرف خارج از سقف متعارف جداست. سورس و حق بازفروش شامل اشتراک نیست. این قیمت‌ها پیش از راه‌اندازی فروش و تأیید نهایی محصول، **پیشنهادی** محسوب می‌شوند.

## نصاب عمومی مشتری (پیش از عرضه)

فایل [نصاب Python](installer/bootstrap.py) برای بررسی عمومی قرار گرفته است. این نصاب میراثی برای بررسی عمومی باقی مانده است؛ در مدل Managed Pro مشتری سورس یا بسته نصب دریافت نمی‌کند و ربات توسط تیم PadsBot روی سرورهای خودمان راه‌اندازی و مدیریت می‌شود.

**پرداخت و تحویل خودکار هنوز فعال نیست:** سرور لایسنس، پرداخت TRC20 و نصب مدیریت‌شده باید عملیاتی و تست شوند. فعلاً وجهی ارسال نکنید.

سورس اصلی PHP، سرور خصوصی لایسنس، کلیدها و فایل‌های انتشار تجاری در این مخزن Public قرار ندارند.

## محتوای ویترین

صفحه واکنش‌گرای معرفی محصول در فایل `index.html` قرار دارد و برای GitHub Pages مناسب است. برای اطلاع از موجودبودن نسخه قابل خرید و شرایط لایسنس از [پروفایل توسعه‌دهنده](https://github.com/MrHamidRouter) استفاده کنید.

**وضعیت:** عرضه عمومی و پرداخت خودکار هنوز فعال و تست نشده است.

**توسعه‌دهندگان:** Mr.HamidRouter و AlirezaX5
