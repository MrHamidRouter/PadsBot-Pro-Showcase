# معرفی PadsBot Pro

**ویترین عمومی محصول تجاری PadsBot Pro** — این مخزن فقط برای معرفی و مستندات عمومی است؛ سورس اصلی PHP، اطلاعات مشتریان، توکن‌ها و بکاپ‌ها در آن قرار نمی‌گیرند.

## تعرفه پیشنهادی

| دوره | دلار |
|---|---:|
| ماهانه | ۱۰ |
| سه‌ماهه | ۲۷ |
| شش‌ماهه | ۵۴ |
| سالانه | ۹۹ |

هزینه سرور، دامنه و پنل‌های شخص ثالث با خریدار است. سورس و حق بازفروش شامل اشتراک نیست. این قیمت‌ها پیش از راه‌اندازی فروش و تأیید نهایی محصول، **پیشنهادی** محسوب می‌شوند.

## نصاب عمومی مشتری (پیش از عرضه)

فایل [نصاب Python](installer/bootstrap.py) برای بررسی عمومی قرار گرفته است. این نصاب هنگام راه‌اندازی، کلید خریداری‌شده را بدون نمایش روی صفحه دریافت می‌کند، دامنه مجاز را بررسی می‌کند، از طریق HTTPS با سرور لایسنس ارتباط می‌گیرد و صحت بسته دریافتی را با SHA-256 کنترل می‌کند.

**هنوز قابل استفاده برای نصب مشتری نیست:** دامنه نهایی سرور لایسنس فعال نشده، بسته تجاری برای تحویل تأیید نهایی نشده و سیستم پرداخت خودکار آماده نیست. پس از انجام تست‌های واقعی، آدرس فعال‌سازی و دستور نصب مشتری در همین بخش منتشر می‌شود.

سورس اصلی PHP، سرور خصوصی لایسنس، کلیدها و فایل‌های انتشار تجاری در این مخزن Public قرار ندارند.

## محتوای ویترین

صفحه واکنش‌گرای معرفی محصول در فایل `index.html` قرار دارد و برای GitHub Pages مناسب است. برای اطلاع از موجودبودن نسخه قابل خرید و شرایط لایسنس از [پروفایل توسعه‌دهنده](https://github.com/MrHamidRouter) استفاده کنید.

**وضعیت:** عرضه عمومی و پرداخت خودکار هنوز فعال و تست نشده است.

**توسعه‌دهندگان:** Mr.HamidRouter و AlirezaX5
